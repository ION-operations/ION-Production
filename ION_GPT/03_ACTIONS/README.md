# 03 Actions

There are two Custom GPT Action schemas.

## 1. ION Action Gateway

Folder:

```text
ion-actions.helixion.net/
```

Use:

```text
SCHEMA_TO_PASTE.yaml
```

## 2. ION MCP Action

Folder:

```text
ion.helixion.net_mcp/
```

Use:

```text
SCHEMA_TO_PASTE.yaml
```

Do not use historical schemas unless a new release bundle explicitly says so.
