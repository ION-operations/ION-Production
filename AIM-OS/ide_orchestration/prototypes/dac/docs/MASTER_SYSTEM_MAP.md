## 🔗 **CORE SYSTEM CONNECTIONS**

```
CMC (Foundation)
├── HHNI (indexes CMC atoms)
├── VIF (stores witnesses in CMC)
├── SEG (stores graph in CMC)
├── APOE (stores plans in CMC)
├── TCS (stores timeline in CMC)
└── CAS (stores analysis in CMC)

HHNI (Retrieval)
├── APOE (retrieves context)
├── VIF (retrieves historical witnesses)
└── SEG (retrieves related evidence)

VIF (Verification)
├── APOE (gates execution)
├── SEG (verifies graph integrity)
└── SDF-CVF (verifies quartet parity)

SDF-CVF (Quality)
├── CMC (stores quartet snapshots)
├── VIF (verifies confidence)
├── APOE (gates execution)
├── HHNI (validates context)
├── SEG (validates synthesis)
├── CAS (validates analysis)
└── TCS (validates timeline)

APOE (Orchestration)
├── CMC (stores execution history)
├── HHNI (retrieves context)
├── VIF (gates execution)
├── SEG (synthesizes knowledge)
└── TCS (tracks execution)

TCS (Timeline)
├── CMC (stores timeline entries)
├── ALL systems (tracks context)
└── CAS (analyzes patterns)

CAS (Analysis)
├── CMC (stores analysis)
├── TCS (analyzes timeline)
└── IIS (uses intuition)
```
