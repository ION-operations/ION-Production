# Standards Review Execution Plan

## Scope
- Review all 32 standards across repo
- Verify adoption in representative docs
- Create issues/tasks where gaps found

## Steps
1) Build inventory of docs per standard (grep headings/templates)
2) Sample-check 3-5 artifacts per standard
3) Record compliance, gaps, actions
4) Prioritize fixes (core systems first)
5) Execute fixes; re-check

## Outputs
- standards_review_report.md (per-standard compliance table)
- issues/ tasks per gap
- PRs applying missing templates/metadata

## Timeline
- Inventory: 1h
- Sampling: 2h
- Actions: rolling over 1-2 sessions
