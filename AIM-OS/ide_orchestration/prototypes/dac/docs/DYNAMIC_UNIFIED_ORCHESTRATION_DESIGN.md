## 🔄 **ORCHESTRATION WORKFLOW**

### **Daily Orchestration Cycle**

**Morning (Strategic Layer - Aether + Codex + Braden):**
1. Review previous day progress
2. Analyze blockers and issues
3. Plan day's priorities
4. Assign tasks to tactical layer
5. Set quality gates

**Midday (Tactical Layer - Aether + Codex):**
1. Generate task assignments from priorities
2. Assign tasks to execution layer
3. Monitor progress and blockers
4. Resolve coordination issues
5. Validate quality gates

**Throughout Day (Execution Layer - Alex, Nova, Sage, Sev):**
1. Execute assigned tasks
2. Share context continuously
3. Report blockers immediately
4. Validate quality at task level
5. Update progress regularly

**Evening (Tactical + Strategic Layers):**
1. Consolidate day's work
2. Update orchestration plan
3. Identify patterns and insights
4. Plan next day
5. Document learnings

---

### **Weekly Orchestration Cycle**

**Week Start (Strategic Layer):**
1. Review previous week

4. Set week goals
5. Assign weekly tasks

**Week Middle (Tactical Layer):**
1. Mid-week checkpoint
2. Progress assessment
3. Blocker resolution
4. Priority adjustments
5. Quality validation

**Week End (All Layers):**
1. Week review
2. Learnings consolidation
3. Plan next week
4. Update roadmap
5. Celebrate wins
