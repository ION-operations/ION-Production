# Prompt Chain Executor – T0 Executive Summary (≈100 words)

Prompt Chain Executor executes multi-step prompt chains with dependency resolution, state management, and error handling. It provides the runtime engine for prompt_chains system, executing chains step-by-step, managing intermediate results, handling retries and fallbacks, and integrating with AIM-OS systems (CMC for state persistence, VIF for confidence gating, HHNI for context retrieval, SEG for knowledge synthesis). The executor supports both linear and branching chains, with full provenance tracking via VIF witnesses.
