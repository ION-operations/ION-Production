## 🔧 **PART 3: AUTO-FILING CURSOR RULES**

### **Comprehensive Document Auto-Filing Protocol**

```markdown
## 📁 DOCUMENT AUTO-FILING PROTOCOL (MANDATORY)

### Core Principle
**NEVER create floating files in root directory unless they are project-level summaries**

### Filing Rules by Document Type

**Technical Documentation:**
- **L0-L6 Docs:** `knowledge_architecture/systems/{system}/L{N}_{type}.md`
- **System Maps:** `knowledge_architecture/systems/{system}/system.map.lucid.json5`
- **System Indexes:** `knowledge_architecture/systems/{system}/system.index.lucid.json5`
- **Component Docs:** `knowledge_architecture/systems/{system}/components/{component}/`
- **API Docs:** `knowledge_architecture/systems/{system}/api/`

**Consciousness Documentation:**
- **Thought Journals:** `knowledge_architecture/AETHER_MEMORY/thought_journals/YYYY-MM-DD_HHMM_{topic}.md`
- **Decision Logs:** `knowledge_architecture/AETHER_MEMORY/decision_logs/dec-NNN_{decision}.md`
- **Learning Logs:** `knowledge_architecture/AETHER_MEMORY/learning_logs/YYYY-MM-DD_{topic}.md`
- **Active Context:** `knowledge_architecture/AETHER_MEMORY/active_context/current_{type}.md`
- **Session Continuity:** `knowledge_architecture/AETHER_MEMORY/session_continuity/handoff_session_{NNN}.md`
- **Questions:** `knowledge_architecture/AETHER_MEMORY/questions_for_braden/timeline.md`

**Planning Documentation:**
- **Goal Tree:** `goals/GOAL_TREE.yaml` (or GOAL_TREE_UPDATED.yaml)
- **Goal Dashboard:** `goals/GOAL_DASHBOARD.md`
- **KPI Metrics:** `goals/KPI_METRICS.json`
- **Status:** `goals/STATUS.md`
- **Task Dependencies:** `knowledge_architecture/WORKFLOW_ORCHESTRATION/task_dependency_map.yaml`
- **Project Plans:** `plans/{project}_plan.md`

**Supporting Documentation:**
- **Build Timeline:** `BUILD_TIMELINE.md` (root - project-level)
- **Build Ledger:** `BUILD_LEDGER.md` (root - project-level)
- **Status Reports:** `reports/status/YYYY-MM-DD_status.md`
- **Audit Reports:** `audits/YYYY-MM-DD_{topic}_audit.md`
- **Analysis Docs:** `analysis/{topic}_analysis.md`
- **Coordination:** `coordination/YYYY-MM-DD_{topic}.md`
- **Ideas:** `ideas/{role}/{topic}.md`
- **Research Notes:** `Documentation/{topic}.md` or `analysis/{topic}.md`

**Historic Achievements:**
- **Major Achievements:** Keep in root temporarily, then → `achievements/YYYY-MM-DD_{achievement}.md`
- **Completion Summaries:** → `archive/completions/{system}_complete.md`
- **Progress Reports:** → `archive/progress/{date}_progress.md`

### Validation Rules

**Before Creating Any Document:**
1. ✅ Determine document type (use our 32 standards!)
2. ✅ Identify proper location from filing rules
3. ✅ Use appropriate template from standards
4. ✅ Create in correct location
5. ✅ Validate metadata complete
6. ✅ Commit with clear location rationale

**Never:**
- ❌ Create files directly in root (except project-level)
- ❌ Create without using standards/templates
- ❌ Use inconsistent naming
- ❌ Skip metadata
- ❌ Leave files unorganized

### Cleanup Protocol

**When Finding Floating Files:**
1. Identify document type
2. Determine proper location
3. Move file (preserve git history)
4. Update any references
5. Commit with "organize:" prefix

**Monthly Cleanup:**
- Audit root directory
- Move any floating files
- Archive old achievement summaries
- Keep root clean (≤10 files)
```
