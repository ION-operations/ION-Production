## 🔑 **KEYWORDS**

### **Core Concepts:**
- **Storyboard:** Central hub that orchestrates all Director workflows
- **Multi-Layer System:** Draft → Formalized workflow (two layers)
- **Script Alignment:** Two-way sync (click scene → panel, click panel → scene)
- **Automation Pipelines:** 1 image → Full template generation
- **Asset Linking:** Connect to Character, Props, ImageForge, VideoForge
- **Visual Editor:** Drag-and-drop storyboard panels
- **Timeline Integration:** Scene tracking with TCS
- **Node Graph Integration:** Visual workflow representation

### **Automation Concepts:**
- **Character Automation:** 1 image → 20+ images (views, expressions, poses)
- **Props Automation:** 1 image → 7+ images (views, detail shots)
- **Scene Automation:** 1 image → 4 views (front, side, back, top)
- **Template Completion:** Automated generation of full character/prop/scene templates

## ⚠️ **IMPORTANT THINGS**

### **Critical Principles:**
- ⚠️ **Central Hub:** Storyboard orchestrates ALL workflows - it's the heart of Director
- ⚠️ **Script Alignment:** Two-way sync is critical - users must be able to click either direction
- ⚠️ **Automation is Powerful:** 1 image → 20+ images is transformative - enable this workflow
- ⚠️ **Asset Linking:** Seamless connection to all modules is essential
- ⚠️ **Visual-First:** Drag-and-drop panels make storyboarding intuitive
- ⚠️ **Multi-Layer Complexity:** Draft → Formalized workflow requires careful state management

### **Key Insights:**
- 💡 **Storyboard is Central:** Everything flows through storyboard
- 💡 **Automation Saves Time:** 1-image workflows are game-changing
- 💡 **Script Alignment is Unique:** Two-way sync is a differentiator
- 💡 **Asset Linking is Critical:** Seamless module integration is essential

### **Gotchas:**
- ⚠️ **State Management:** Multi-layer system requires careful state management
- ⚠️ **Script Sync:** Two-way sync between scripts and panels is complex
- ⚠️ **Automation Triggers:** Triggering automation from storyboard requires careful orchestration
- ⚠️ **Asset Loading:** Linking to assets in other modules requires async loading
