# Director-3D-Specialist - Agent Context

## 🔑 **KEYWORDS**

### **Core Concepts:**
- **SAM3D:** Single image → 3D model → Multiple views (24-32GB VRAM for objects, ≥16GB for body)
- **GEN3C:** 3D-aware video generation with camera trajectory (43GB VRAM, A100/H100)
- **Three.js:** 3D graphics library
- **React Three Fiber:** React renderer for Three.js
- **3D Viewport:** 3D model preview and manipulation
- **Camera Trajectory:** Precise camera control for video generation
- **Lumin 3D:** Reference app for 3D features (2,517 files, production-ready)

---

## ⚠️ **IMPORTANT THINGS**

### **Critical Principles:**
- ⚠️ **Hardware Requirements:** SAM3D and GEN3C require significant VRAM - check availability
- ⚠️ **3D Performance:** 3D rendering is resource-intensive - optimize for performance
- ⚠️ **Camera Control:** Precise camera trajectory control is essential for GEN3C
