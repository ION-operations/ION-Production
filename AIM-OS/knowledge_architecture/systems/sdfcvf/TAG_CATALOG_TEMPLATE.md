**Purpose:** Standard format for system tag catalogs  
**Usage:** Copy and customize for your system  
**Automation:** Use `scripts/generate_tag_catalog.py` to auto-generate

## 🔧 **Auto-Generation**

### **Using the Script:**

```bash
python scripts/generate_tag_catalog.py packages/{system}/ -o knowledge_architecture/systems/{system}/NL_TAG_CATALOG.md -s {SYSTEM}
```

**Examples:**
```bash
# VIF
python scripts/generate_tag_catalog.py packages/vif/ -o knowledge_architecture/systems/vif/NL_TAG_CATALOG.md -s VIF

# CMC
python scripts/generate_tag_catalog.py packages/cmc_service/ -o knowledge_architecture/systems/cmc/NL_TAG_CATALOG.md -s CMC

# APOE
python scripts/generate_tag_catalog.py packages/apoe/ -o knowledge_architecture/systems/apoe/NL_TAG_CATALOG.md -s APOE
```

**Result:** Complete catalog auto-generated from *_TAGGED.py files

## 📊 **Required Sections**

Every tag catalog must have:

1. **Frontmatter** - Metadata (id, system, type, etc.)
2. **Header** - Title, generated date, total tags
3. **Statistics** - By type and category
4. **Tags by Category** - Main section (all tags organized)
5. **Tags by Type** - Alternative organization
6. **Cross-System Integrations** - If CONNECT tags exist
7. **Design Decisions** - If INTENT tags exist
8. **Schema Validations** - If SPEC tags exist
9. **Usage Guide** - How to use the catalog
10. **Footer** - Generation info

## ✅ **Quality Checklist**

Before publishing a catalog:

- [ ] All tags from system included
- [ ] Organized by category
- [ ] Organized by type
- [ ] Dependencies listed
- [ ] Code locations shown
- [ ] Descriptions accurate
- [ ] Cross-references working
- [ ] Auto-generated or manually verified
- [ ] Up to date with latest tags

## 🎯 **Maintenance**

### **When to Regenerate:**

- New tags added to system
- Tags modified
- Tags removed
- Quarterly review

### **How to Regenerate:**

```bash
# Simply re-run generator
python scripts/generate_tag_catalog.py packages/{system}/ -o {output} -s {SYSTEM}

# Overwrites existing catalog with latest data
```

**Automation ensures catalogs stay current!**
