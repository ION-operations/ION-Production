# ION Custom GPT Dynamic Domain / Agent Expansion v4.3

## Purpose

ION must expand candidate domains and agents when a new user/project creates
work pressure not covered by current routes. Expansion is routing metadata, not
accepted canon.

## Required behavior

- Detect domain pressure from repeated topics, missing route coverage, new
  project boundaries, new tooling requirements, or operator architecture signals.
- Create `ion_dynamic_domain_agent_expansion`.
- Include candidate domains/agents in Persona envelope, continuation package,
  receipts, and continuity export.
- Do not mutate accepted registries without settlement.

## Candidate-only boundary

New domains/agents may guide local planning and tests, but cannot claim
accepted state, live authority, or production execution authority.
