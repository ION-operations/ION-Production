# ION Domain Context Capsule README / Context Mesh v4.5

## Purpose

Every significant folder should explain how an ION agent enters and works there.
README.md is the human capsule projection; ION_CONTEXT_CAPSULE.yaml is the
machine contract.

## Folder capsule must include

- identity and purpose
- authority boundaries
- read-first files
- active objectives
- local agents/domains
- safe tests and automations
- unsafe actions requiring approval
- canonical surfaces
- history and receipts
- continuity export obligations
- freshness/drift markers
- boundaries / do-not rules

## Context mesh

Incoming agents mount local capsule + parent capsules + root authority before
substantive work. Local capsules never override operator instruction, repo
authority, or proof receipts.
