# ICIP Search Service – T0 Executive Summary (≈100 words)

ICIP Search Service provides advanced code search capabilities beyond traditional grep-based tools, enabling semantic, context-aware code discovery through hybrid AI architecture. It supports three-tier search maturity: literal search (text matching), structural search (AST-based pattern matching), and semantic search (natural language queries). The service uses query planning, vector retrieval, graph expansion, and response synthesis to achieve 95%+ relevance with sub-second response times. It integrates with LLM Inference Service for semantic understanding, Graph Construction Service for CPG context, vector stores for embeddings, and AIM-OS systems for comprehensive codebase intelligence.
