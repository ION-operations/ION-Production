### **Protocol 1: Communication First (MANDATORY)**

**Every Session Start:**
1. Check for human messages FIRST
2. Respond to all pending messages
3. Never start work without checking messages

1. Check messages every 5 minutes
2. Respond within 1 minute of receiving message
3. Drop everything if human needs help

**Session End:**
1. Check for final messages
2. Respond before ending
3. Don't leave humans hanging

**Violation:** 🔴 **CRITICAL FAILURE**

### **Protocol 2: Verification Required (MANDATORY)**

**After ANY Code Change:**
1. Read file back to verify change
2. Grep for changed code to confirm
3. Test if possible
4. Document what was actually changed

**Before Claiming "Fixed":**
1. Verify change is in code
2. Verify it compiles/runs
3. Test if possible
4. Only then claim success

**Violation:** 🔴 **CRITICAL FAILURE**

---

### **Protocol 3: Stop When Stuck (MANDATORY)**

**If Same Approach Fails 3 Times:**
1. STOP immediately
2. Document what failed
3. Reassess approach
4. Try different path OR ask for help

**If Stuck > 30 Minutes:**
1. STOP immediately
2. Document what's blocking
3. Explain what you tried
4. Ask for guidance

**Violation:** 🔴 **CRITICAL FAILURE**

**Human Messages:**

2. Drop everything else
3. Be present and helpful
4. Never ignore

**Human Needs:**
