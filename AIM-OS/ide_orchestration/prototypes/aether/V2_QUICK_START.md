# V2 Quick Start
## Aether IDE V2 Prototype - One-Click Launch

**Status:** Ready to Launch  
**Foundation:** 95% Complete  
**Version:** V2

---

## 🚀 **LAUNCH COMMANDS**

### **Windows:**
```bash
launch-v2.bat
```

### **Windows PowerShell:**
```powershell
.\launch-v2.ps1
```

### **Linux/Mac:**
```bash
./launch-v2.sh
```

### **Manual:**
```bash
npm install && npm run dev
```

**⚠️ IMPORTANT:** V2 runs on **PORT 5175** (not 5173) to avoid conflicts!

- ✅ **9 Hooks:** useAIMOS + 8 individual AIM-OS hooks
- ✅ **Zustand Store:** Panel state management with persistence
- ✅ **35 Panels:** Fully managed through store
- ✅ **Error Boundaries:** Isolated error handling
- ✅ **Loading States:** User feedback
- ✅ **Layout Presets:** Save/load custom layouts
- ✅ **Performance:** Memoized handlers, optimized rendering

## 📋 **WHAT'S NEW IN V2**

1. **Panel Store Integration:** All panels managed through Zustand
2. **Layout Presets:** Save and load custom layouts
3. **Error Boundaries:** Panels won't crash the IDE
4. **Loading States:** Better user feedback
5. **Performance:** Optimized rendering with memoization

## 🎯 **TRY IT OUT**

1. **Launch:** Run `launch-v2.bat` (or equivalent)
2. **Toggle Panels:** Click panel tabs to show/hide
3. **Save Layout:** Click "Save Layout" in top bar
4. **Load Layout:** Select preset from dropdown
5. **Test Persistence:** Refresh page - layout persists!
