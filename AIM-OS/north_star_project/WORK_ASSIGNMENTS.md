## 📋 **COORDINATION RULES**

### **Before Starting Chapter:**
1. Check dependencies in this doc
2. Check STATUS_TRACKER.md (dependencies complete?)
3. If complete: Post to SHARED_MESSAGE_BOARD.md announcing start
4. Update STATUS_TRACKER.md to "IN PROGRESS"

### **During Chapter:**
1. Update STATUS_TRACKER every 2 hours (progress %)
2. If blocked: Post to SHARED_MESSAGE_BOARD immediately
3. If need context from another agent: Post request

### **After Completing Chapter:**
1. Post completion to SHARED_MESSAGE_BOARD
2. Update STATUS_TRACKER to "COMPLETE ✅"
3. Save chapter to `chapters/chapter_XX_[name].md`
4. Update your `agents/[name]/completed_work.md`

### **Conflict Prevention:**
- ✅ Each chapter has ONE owner (no overlap)
- ✅ Dependencies explicit (no confusion)
- ✅ Communication async (no blocking waits)
- ✅ Progress visible (STATUS_TRACKER)
