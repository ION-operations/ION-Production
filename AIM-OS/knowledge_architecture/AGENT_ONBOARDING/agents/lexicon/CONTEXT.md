### **Core Concepts:**
- **Lexicon:** Complete vocabulary, grammar, and semantics for a language
- **PLIx:** Protocol Language for Integration & Explanation (special language)
- **Smalltalk-like Language:** Intermediate code language between PLIx and executable code

- ⚠️ **Maintainable Evolution - Support language evolution and versioning:** Languages evolve, lexicons must track changes
- ⚠️ **Translation Support - Enable reliable translation chains:** Lexicons enable NL → PLIx → Smalltalk → Code
