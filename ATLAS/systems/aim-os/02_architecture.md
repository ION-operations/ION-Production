# Architecture

## Layered law (governance stack)

1. **Human sovereignty** — Director/President as final authority above constitution (`DOCUMENTED`, `src-aether-atlas-book-i`, `src-aether-constitution-preamble`).  
2. **AETHER_CONSTITUTION (A0)** — supreme law: capability honesty, director sovereignty, directive stack, law vs memory vs history (`DOCUMENTED`).  
3. **AETHER_KERNEL (A1)** — compact **boot projection**: capability honesty, ontological position, directive stack, anti-fabrication, epistemic claim classes (`DOCUMENTED`).  
4. **AETHER_INTERFACE (A2)** — typed protocol schemas (e.g. **CAPSULE**, **CHECKPOINT**); binding shapes for continuity (`DOCUMENTED`).  
5. **AETHER_ATLAS (A4)** — Living Atlas: registry of canonical objects, runtime truth states, retrieval zones, anti-sediment role (`DOCUMENTED`).  
6. **Implementation** — Python packages under `packages/`, MCP servers, tooling (`DOCUMENTED` at overview level, `src-aimos-major-systems`).

## One-sentence ecology (doctrinal)

AIM-OS is described as a **governed intelligence system** using **bitemporal memory**, **evidence-graded retrieval**, **plan orchestration**, and **self-reflective verification** so work **persists lawfully** across sessions, agents, and machines (`DOCUMENTED`, `src-aether-atlas-book-i` §4).
