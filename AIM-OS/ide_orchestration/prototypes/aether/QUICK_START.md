# Aether IDE Prototype - Quick Start

**One-Click Launcher:** `npm run dev`

## 🚀 **Quick Start**

```bash
# Install dependencies
npm install

# Launch prototype (one-click!)
npm run dev
```

The prototype will open automatically at `http://localhost:5173`
