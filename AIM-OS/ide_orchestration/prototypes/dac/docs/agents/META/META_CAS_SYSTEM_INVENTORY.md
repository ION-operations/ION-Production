## 🏗️ **SYSTEM STRUCTURE**

### **Internal Components (7):**

1. **activationTracker**
   - **Responsibility:** Tracks what's "hot" vs "cold" in AI attention
   - **Status:** Production
   - **Perf Budget:** 10ms
   - **Security Level:** Medium
   - **Must Never:** Lose activation state, allow activation failures, skip warnings, create inconsistent data

2. **categoryRecognizer**
   - **Responsibility:** Detects how tasks get classified and validates against actual requirements
   - **Status:** Production
   - **Perf Budget:** 15ms
   - **Security Level:** Medium
   - **Must Never:** Miss category errors, allow wrong categorization, skip validation, lose reasoning

3. **attentionMonitor**
   - **Responsibility:** Monitors cognitive load and attention narrowing
   - **Status:** Production
   - **Perf Budget:** 8ms
   - **Security Level:** Low
   - **Must Never:** Miss attention narrowing, allow overload, skip warnings, lose metrics

4. **failureModeDetector**
   - **Responsibility:** Detects cognitive failure modes and patterns
   - **Status:** Production
   - **Perf Budget:** 20ms
   - **Security Level:** High
   - **Must Never:** Miss failure patterns, skip analysis, lose context, allow failures to repeat

5. **learningExtractor**
   - **Responsibility:** Extracts learnings from decisions and outcomes
   - **Status:** Production
   - **Perf Budget:** 25ms
   - **Security Level:** Medium
   - **Must Never:** Lose learning opportunities, skip extraction, create false learnings, lose provenance

6. **introspectionEngine**
   - **Responsibility:** Performs hourly cognitive introspection and validation
   - **Status:** Production
   - **Perf Budget:** 30ms
   - **Security Level:** High
   - **Must Never:** Skip introspection cycles, lose data, allow drift to go undetected, create inconsistent introspection

7. **decisionLogger**
   - **Responsibility:** Logs all decisions with full context and reasoning
   - **Status:** Production
   - **Perf Budget:** 5ms
   - **Security Level:** Critical
   - **Must Never:** Lose decision logs, skip logging, create incomplete logs, allow log tampering

### **Integration Ports (5):**

1. **apoeIntegration**
   - **Direction:** Bidirectional
   - **Connects To:** APOE (AI-Powered Orchestration Engine)
   - **Protocol:** Internal API
   - **Security Level:** High
   - **Data Exchanged:** decision_events, execution_context, plan_analysis, cognitive_state
   - **Purpose:** Observes APOE decision-making processes, tracks reasoning transparency, validates protocol activation

2. **vifIntegration**
   - **Direction:** Bidirectional
   - **Connects To:** VIF (Verifiable Intelligence Framework)
   - **Protocol:** Internal API
   - **Security Level:** High
   - **Data Exchanged:** confidence_scores, provenance_data, verification_results, cognitive_metrics
   - **Purpose:** Analyzes VIF confidence scores, adds cognitive context to witness envelopes, enhances confidence calibration

3. **hhniIntegration**
   - **Direction:** Bidirectional
   - **Connects To:** HHNI (Hierarchical Hypergraph Neural Index)
   - **Protocol:** Internal API
   - **Security Level:** Medium
   - **Data Exchanged:** context_queries, retrieval_context, activation_context, cognitive_load_data
   - **Purpose:** Analyzes HHNI context usage, informs retrieval with activation-awareness, improves context relevance

4. **cmcIntegration**
   - **Direction:** Bidirectional
   - **Connects To:** CMC (Context Memory Core)
   - **Protocol:** Internal API
   - **Security Level:** Critical
   - **Data Exchanged:** cognitive_analyses, decision_logs, introspection_data, learning_data
   - **Purpose:** Stores decision logs and cognitive analysis in CMC, enables meta-learning and pattern recognition

5. **sdfcvfIntegration**
   - **Direction:** Bidirectional
   - **Connects To:** SDF-CVF (Atomic Evolution Framework)
   - **Protocol:** Internal API
   - **Security Level:** Medium
   - **Data Exchanged:** quality_metrics, failure_patterns, evolution_recommendations, cognitive_analysis
   - **Purpose:** Provides quality insights and failure mode context to SDF-CVF, helps understand why violations occurred
