## Direct Comparative Reading

- Method notes are strongest when the question is "what does this check really justify?" because they police over-read better than any sibling family.
- Explicit boundary definitions are strongest when the question is "what exactly do these words mean here?" because they give the sharpest local semantics.
- Findings boards are strongest when the question is "what is the current best reading across the latest evidence passes?" because they synthesize the active packet trail into one dated interpretation.
- Startup and runbook doctrine is strongest when the question is "what trust path or fail-closed rule should guide execution?" because it preserves operational law rather than evidence synthesis.
- Comparison narratives are strongest when the question is "how do these sibling families relate, disagree, and constrain one another?" because they are built for direct arbitration prose.

## Visible Interpretation Contradictions

1. Method notes and boundary sections explicitly limit what a result means, while findings boards and comparison narratives necessarily compress those limits into broader readings.
2. Startup and runbook doctrine can sound authoritative about how to trust MCP reachability, but it is not direct evidence of the current host state and still contains Codex bootstrap examples addressed to `sev`, which is visible lane drift for the present CODEX router.
3. Findings boards provide the freshest synthesized interpretation among file surfaces, but they remain syntheses rather than the local semantic source of any status term.
4. Comparison narratives are strongest at arbitration language, but they inherit the datedness and hidden assumptions of the sibling surfaces they compare.
5. Boundary-definition surfaces are locally sharp, but there is no single file in this packet family that elevates one boundary section into an organism-wide interpretation canon.
