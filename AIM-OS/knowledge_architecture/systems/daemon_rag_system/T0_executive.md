# Daemon/RAG System – T0 Executive Summary (≈100 words)

Daemon/RAG System provides intelligent management of MCP tools to solve Cursor IDE's 40-tool limit through context-aware tool selection, dynamic server management, and RAG-enhanced decision making. It analyzes user input to select optimal subset of 40 tools from 51 available, manages 12 MCP server instances, and continuously learns from usage patterns. Key capabilities include context analysis, dynamic selection, server orchestration, performance monitoring, and learning system. Integrates with all LUCID-MCP tools, Cursor IDE, and AIM-OS systems.
