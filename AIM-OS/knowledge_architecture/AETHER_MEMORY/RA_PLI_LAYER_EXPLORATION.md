## 🔍 **WHAT IS PL/I?**

### Historical Context

**PL/I (Programming Language One)** was developed in the 1960s as a bridge:
- **Scientific Computing** (FORTRAN-style)
- **Business Computing** (COBOL-style)
- **System Programming** (ALGOL-style)

**Multics** was an operating system project (1960s-70s) that used PL/I extensively. Multics influenced Unix and modern operating systems.

### Key Characteristics of PL/I

1. **Multi-paradigm**: Procedural, structured, object-oriented concepts
2. **Type system**: Rich type system with automatic conversions
3. **Exception handling**: Built-in error handling mechanisms
4. **String manipulation**: Powerful string operations
5. **File handling**: Sophisticated I/O capabilities
6. **Concurrency**: Early support for parallel processing
