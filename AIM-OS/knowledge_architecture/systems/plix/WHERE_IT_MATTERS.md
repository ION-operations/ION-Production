## Where PLIx Matters Most

**The Problem:**
- Current development is *implementation-driven* (we build how things work)
- No way to express *intent* separately from *implementation*
- No way to verify *intent* was achieved

**How PLIx Helps:**
- PLIx enables *intent-driven development* (we express what we want, then build how to achieve it)
- Intent is expressed *purely* (without implementation details)
- Intent can be verified *independently* (check postconditions)

**Why This Matters:**

- Learning becomes *intent-driven* (we learn how to better achieve intents)
