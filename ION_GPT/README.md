# ION GPT

This folder is organized for a non-coder configuring the ION Custom GPT.

Use folders in order:

```text
01_GPT_BUILDER_INPUTS/
02_PACKAGES_TO_UPLOAD/
03_ACTIONS/
04_CURRENT_SANDBOX_CARRIER/
90_HISTORICAL_ZIPS/
99_WORKER_DETAILS/
```

## What to open first

```text
01_GPT_BUILDER_INPUTS/README.md
```

## What not to use by default

- `90_HISTORICAL_ZIPS/` is old evidence.
- `99_WORKER_DETAILS/` is for AI/Codex workers.
- Generated upload zips are not stored here; they are in `ION_EXPORTS_LOCAL/`.
