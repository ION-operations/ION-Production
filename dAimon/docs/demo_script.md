# dAimon three-minute demo script

## 0:00–0:25 — Hook

Meet dAimon: a governed AI continuity daemon for Gemini agents. Gemini can generate useful work; dAimon decides what becomes trusted future context.

## 0:25–1:00 — Import

Import a messy file bundle. The kernel classifies continuity objects and places every candidate into a settlement queue.

## 1:00–1:45 — Settle

Accept high-authority items, request proof for low-authority synthesis, defer tasks, reject unsafe claims.

## 1:45–2:25 — Receipt

Issue a receipt candidate. Show proof hash, non-claims, and inheritable object IDs.

## 2:25–3:00 — Next session

Gemini asks MongoDB MCP for governed state. It receives only receipt-cleared continuity objects.
