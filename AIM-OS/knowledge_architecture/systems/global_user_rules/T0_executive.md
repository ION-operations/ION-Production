# Global User Rules – T0 Executive Summary (≈100 words)

Global User Rules provides centralized configuration and rule management for AIM-OS user preferences and system behavior. Enables consistent rule application across all AIM-OS systems and agents. Key features include rule definition and management, preference storage, behavior configuration, and rule validation. Integrates with all AIM-OS systems for unified rule application. Agent Identity Protocol ensures proper context attribution and continuity across rule operations.
