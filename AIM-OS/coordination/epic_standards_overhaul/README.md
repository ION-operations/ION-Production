# EPIC Standards Overhaul – Mission Hub

**Purpose:** Central hub for coordinating agents executing Phase 1 standards: L0–L6 docs, System Maps, System Index, Metadata, Validation Framework, Templates.

## Shared Locations
- Tracking: `plans/EPIC_STANDARDS_TRACKING.md`
- Standards Index: `knowledge_architecture/STANDARDS_NAV_INDEX.md`
- Gates: `knowledge_architecture/validation/`
- Artifacts: `coordination/epic_standards_overhaul/artifacts/`
- Missions: `coordination/epic_standards_overhaul/missions/`
 - Onboarding: `coordination/epic_standards_overhaul/ONBOARDING.md`
 - Comms: `coordination/epic_standards_overhaul/comms/`

## Agents & Roles
- Implementation Agent(s): Aether (per-mission briefs below)
- Reviewer: Braden (PR acceptance, gate enforcement)

## Cadence & Checkpoints
- Daily batch: 3–6 items
- Checkpoint: end-of-day update in `coordination/epic_standards_overhaul/artifacts/daily_reports/`
- Merge Gate: all relevant validation checklists must pass

## Communication Protocol
- Each PR links gate sheets + updates tracker
- Questions recorded in `knowledge_architecture/AETHER_MEMORY/questions_for_braden/`
- Decisions logged in `knowledge_architecture/AETHER_MEMORY/decision_logs/`
 - Use `comms/SHARED_MESSAGE_BOARD.md` for async updates; daily report template provided
