# WisdomNET

Status: workspace_family_candidate

WisdomNET is the memory, context, and intelligence-lineage family inside the ION Production workspace.

Its role is to develop durable knowledge structures, retrieval patterns, context continuity models, and wisdom-oriented memory systems that can support ION, dAimon, ATLAS, and future agents.
