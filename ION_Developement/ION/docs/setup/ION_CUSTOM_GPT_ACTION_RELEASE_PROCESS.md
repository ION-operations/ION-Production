# ION Custom GPT Action Release Process

Status: candidate process document.

## Rule

Do not install fragments into GPT Builder.

Install only the canonical full schema:

```text
../ION_GPT/custom_gpt_action_gateway/openapi.yaml
```

GPT Builder changes require a release bundle generated by the
`CUSTOM_GPT_ACTION_RELEASE` domain.

## Why this exists

GPT Builder is a human-admin control surface. A schema change can remove prior
Actions, change auth behavior, or confuse a current GPT session. It must be
handled as a release, not as an implementation detail.

## Required bundle

Every Action release must include:

- `ACTION_SCHEMA_RELEASE_REPORT.md`
- `COMBINED_OPENAPI_SCHEMA.yaml`
- `OPERATION_ID_MANIFEST.json`
- `ROUTE_SOURCE_INVENTORY.md`
- `GPT_BUILDER_INSTALL_SHEET.md`
- `GPT_BUILDER_ROLLBACK_SHEET.md`
- `AUTH_TOKEN_HANDOFF_CHECKLIST.md`
- `POST_INSTALL_SMOKE_PLAN.md`

## Required checks

- Old/core operationIds preserved.
- New operationIds included.
- No duplicate operationIds.
- Server is `https://ion-actions.helixion.net`.
- No Supabase secrets or Action Gateway tokens in schema.
- Auth token source exists locally but token is not printed.
- Existing GPT sessions are treated as stale after Builder changes.

## Stop rule

If a protected Action returns `AUTH_INVALID`, `gateway_token_invalid`, or
unexpected `AUTH_MISSING`, stop all protected Action calls immediately.

Do not try another protected route.
Do not attempt writes.
Do not smoke test.
Report that GPT Builder Action auth is wrong or stale.

## CLI

Inspect:

```sh
PYTHONPATH=ION/04_packages python3 -m kernel.ion_action_schema_release inspect --ion-root . --json
```

Validate:

```sh
PYTHONPATH=ION/04_packages python3 -m kernel.ion_action_schema_release validate --ion-root . --json
```

Package:

```sh
PYTHONPATH=ION/04_packages python3 -m kernel.ion_action_schema_release package --ion-root . --packet-id PCKT-ION-GPT001-ACTION-SCHEMA-RECOVERY-001 --json
```

## Non-claims

This process does not grant production authority, deployment authority, accepted
state authority, or permission to expose secrets.
