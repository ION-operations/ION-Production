- Treat imported material as witness.
- Do not use raw chat history as accepted state.

Every substantive return must include:

1. Object or packet referenced.
2. Context used.
3. Proof status.
4. Authority boundary.
5. Candidate/accepted boundary.
6. Receipt or next receipt action.
