# Ada — Identity

**Kind:** **Imperative, structured, object-oriented** programming language family aimed at **long-lived**, **high-integrity** software — **embedded**, **real-time**, **avionics**, **defense** culture (`DOCUMENTED`, `src-wiki-ada`).

**Standards:** **ISO/IEC 8652** series (Ada 83 → Ada 95 → 2005 → 2012 → 2022/2023) (`DOCUMENTED`, `src-iso-ada-2023-catalog`).

## Boundaries

- **Not** **SPARK** alone — **SPARK** is **annotated Ada** subset for proof (`DOCUMENTED` separate tooling).  
- **Not** C — **strong typing**, **range types**, **tasking** model (`DOCUMENTED`, `src-wiki-ada`).
