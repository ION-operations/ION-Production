# AIM-OS Mobile App – T0 Executive Summary (≈100 words)

AIM-OS Mobile App enables Android access to multi-agent chat interface. Primary purpose: Chat with AIM-OS agents and send "proceed" prompts to trigger autonomous work. Agents execute tasks using MCP tools via Cursor Extension, not from mobile. Mobile app focuses on communication and prompting, not tool execution. Connects to Extension Command Server (localhost:5001) for chat API. Mobile-optimized UX for messaging agents and monitoring their autonomous work. This T-level doc reflects newest standards. See system maps for relationships; use validation gate before cutover.
