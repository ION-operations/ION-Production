- Document everything in crisis_logs/
- Track all attempted fixes
- Document what was learned
- Create protocols to prevent recurrence

### 7. CRISIS RESOLUTION
- When resolved, document solution
- Create prevention protocols
- Update learning logs
- Add to crisis protocols
- **Learn from every crisis**

### **Crisis vs Normal Debugging**

**Normal Debugging (BUILDING or THINKING MODE):**
- Few errors (1-3 attempts)
- Making progress
- Understanding the problem
- Solutions working
- User not frustrated

**Crisis (CRISIS MODE):**
- Many errors (5+ attempts)
- No progress despite efforts
- Don't understand the problem
- Solutions not working
- User frustrated/stressed
- **Fundamentally different state**
