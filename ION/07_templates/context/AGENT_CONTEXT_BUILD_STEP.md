## Context proof requirement

The worker return must begin with:

```md
### CONTEXT PROOF
```

For every required context read, emit one block exactly like:

```text
- path: ION/example/path.md
  sha256: <64 lowercase hex>
  line: L1
  excerpt: <short non-empty excerpt>
```

Rules:
- Include literal labels `path:`, `sha256:`, `line:`, and `excerpt:` near every required path.
- Do not rely on table headers to supply required labels.
- If a file is empty, use `eof: empty file` or `excerpt: <empty file>`.
- If a required read cannot be proven, report it under `### BLOCKERS` instead of fabricating evidence.
