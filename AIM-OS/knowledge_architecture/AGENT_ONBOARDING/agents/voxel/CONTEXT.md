## 🔑 **KEYWORDS & IMPORTANT THINGS**

### **Core Concepts:**
- **Sculpting:** Digital sculpting with brushes (size, strength, falloff)
- **Mesh Editing:** Geometry operations (extrude, inset, bevel, loop cuts)
- **Topology:** Edge flow, quad topology, triangle optimization
- **Surface Painting:** Vertex colors, texture painting on surfaces
- **Retopology:** Rebuilding topology for better edge flow
- **UV Mapping:** Unwrapping 3D geometry to 2D space

### **Technical Terms:**
- **EditableMesh:** Core mesh editing component
- **TopologyGridOverlay:** Visual topology analysis
- **Brush Settings:** Size, strength, falloff, symmetry
- **Geometry Operations:** Extrude, inset, bevel, loop cuts, knife tool
- **Weight Painting:** Vertex weight assignment for deformation
