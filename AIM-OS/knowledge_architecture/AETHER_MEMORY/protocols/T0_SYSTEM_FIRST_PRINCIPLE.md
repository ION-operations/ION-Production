# System-First Principle - Executive Summary

**Core Principle:** Before creating ANY new system or feature, research existing systems FIRST. We've already thought of almost everything (at least in basic form).

**Escalation Hierarchy:**
1. Research existing systems (codebase, SUPER_INDEX, system maps, docs)
2. Identify overlaps and conflicts
3. Find integration opportunities
4. Enhance rather than replace

**Impact:** Prevents duplication, leverages existing work, saves ~30+ hours per discovery. Mandatory for all development. Violation triggers immediate stop and research requirement.
