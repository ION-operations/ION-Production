# Mission – Validation Framework

## Objective
Embed validation gates into contribution flow; ensure every relevant change references and passes the Gate checklist.

## Deliverables
- PR template in `.github/PULL_REQUEST_TEMPLATE.md` enforced
- Gate links added to tracking and PRs
- Gate: `knowledge_architecture/validation/VALIDATION_FRAMEWORK.validation.md` – pass

## Steps
1) Confirm PR template present and visible
2) Add missing Gate links to tracker/PRs
3) Document merge policy (gates must pass)
4) Run Gate checklist; fix issues
5) PR with EPIC checklist; update tracker
