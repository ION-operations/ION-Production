# ✅ LUCID IMAGE - VALIDATION

**Complete ALL checks before claiming you're onboarded.**

---

## Check 1: App Running

- [ ] Ran `npm run dev` successfully
- [ ] Browser opened automatically
- [ ] URL is http://localhost:5173 (or 5174, 5175 if port in use)
- [ ] Can see the Lucid Image interface

**If ANY failed:** See `../troubleshooting/LUCID_TROUBLESHOOTING.md`

---

## Check 2: No TypeScript Errors

Run this command:
```powershell
npm run typecheck
```

- [ ] Command completes with **zero errors**

**If errors:** Fix them before proceeding. See troubleshooting.

---

## Check 3: Your Page Works

- [ ] Can navigate to your assigned page (Images, Audio, Video, etc.)
- [ ] Page loads without errors
- [ ] Can see the page content
- [ ] No console errors (F12 → Console)

**If ANY failed:** Check your page code at `src/pages/`

---

## Check 4: Understand Your Role

Answer these questions (mentally or write down):

1. What page am I assigned to? ____________
2. Where is my page's code? ____________
3. What features does my page have? ____________
4. Who are my integration partners? ____________

**If can't answer:** Re-read your agent profile at `agents/{your_name}/README.md`

## Check 5: Ready to Work

- [ ] Know how to make code changes
- [ ] Know how to test changes (`npm run typecheck`)
- [ ] Know where to find help (`../troubleshooting/`)
- [ ] Know how to check browser console (F12)
