# ICIP Code Property Graph – T0 Executive Summary (≈100 words)

ICIP Code Property Graph provides unified data model for codebase intelligence, unifying AST (Abstract Syntax Tree), CFG (Control Flow Graph), and DFG (Data Flow Graph) into single queryable graph. It enables comprehensive semantic understanding, complex queries, and advanced analysis across 25+ programming languages with 95% semantic coverage. The CPG integrates with CMC for atom storage, HHNI for physics-based retrieval, VIF for provenance tracking, and SEG for knowledge synthesis, serving as foundation for ICIP Platform's intelligence capabilities.
