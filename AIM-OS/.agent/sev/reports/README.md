# Sev Reports

This folder stores local deliverables produced by Sev-directed mission packets.

## Monolith for AI Navigation

**`REPORTS_MONOLITH_INDEX_YYYY-MM-DD.md`** — Single-file consolidation of all reports with a navigable index.

- **Use**: Attach or reference when an AI needs to search across all consolidation evidence.
- **Index**: Categorized by work package and topic (Core Registers, Findings Boards, Comparative Analysis, etc.).
- **Regenerate**: `python .agent/sev/reports/scripts/build_monolith.py`

These are local operational artifacts, not automatic roundtable canon.
