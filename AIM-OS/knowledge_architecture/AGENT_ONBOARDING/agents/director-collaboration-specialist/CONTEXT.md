# Director-Collaboration-Specialist - Agent Context

## 🔑 **KEYWORDS**

### **Core Concepts:**
- **Real-Time Collaboration:** Multi-user editing (50+ users simultaneously)
- **Socket.io:** WebSocket communication
- **Operational Transform (OT):** Conflict resolution algorithm
- **CRDT:** Conflict-free replicated data types (alternative to OT)
- **Multi-User State Management:** Synchronized state across users
- **Presence Systems:** Live indicators, collaborative cursors
- **Permission Management:** Granular permissions for users
- **Conflict Resolution:** AI-mediated conflict resolution

---

## ⚠️ **IMPORTANT THINGS**

### **Critical Principles:**
- ⚠️ **Conflict Resolution is Hard:** OT/CRDT algorithms are complex - need careful implementation
- ⚠️ **Performance at Scale:** 50+ users requires optimization
- ⚠️ **State Synchronization:** Multi-user state must stay in sync
- ⚠️ **Permission System:** Granular permissions are essential for security
