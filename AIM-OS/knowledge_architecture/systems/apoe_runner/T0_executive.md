# APOE Runner – T0 Executive Summary (≈100 words)

APOE Runner executes compiled APOE plans with role handlers, budget tracking, and quality gates. It provides command-line and programmatic interfaces for running ACL plans, manages execution state, handles errors gracefully, and integrates with all AIM-OS systems (CMC for persistence, VIF for confidence gating, HHNI for context retrieval, SEG for knowledge synthesis). The runner supports both single-plan execution and batch processing, with full provenance tracking via VIF witnesses.
