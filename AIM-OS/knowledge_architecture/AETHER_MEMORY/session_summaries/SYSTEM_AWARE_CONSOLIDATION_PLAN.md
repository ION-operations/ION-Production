## 📝 **CONSOLIDATION WORKFLOW**

**For Each File:**

1. **Identify System** - Which AIM-OS system does it relate to?
2. **Categorize Type** - Is it idea, journal, draft, or archived?
3. **Move to System Folder** - Place in appropriate system subfolder
4. **Extract to T-Levels** - Review and extract key concepts into T0-T6
5. **Update System Index** - Add references in system README
6. **Update SUPER_INDEX** - Add concepts to master index

**Example Workflow:**

```
File: "PATH_A_IMPLEMENTATION_COMPLETE.md"
↓
System: Temporal Consciousness (Timeline + Chains + Goals + Viz)
↓

↓
Move to: systems/temporal_consciousness/docs/path_a_implementation/
↓
Extract: Key architecture decisions → T2_architecture.md
↓
Index: Add reference in temporal_consciousness/README.md
↓
SUPER_INDEX: Add "PATH A Integration" concept
```
