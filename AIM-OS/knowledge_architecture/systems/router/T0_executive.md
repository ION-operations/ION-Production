# Router – T0 Executive Summary (≈100 words)

Router (APOE-MCP Router) is an intelligent tool selection system that chooses the right MCP tool at the right moment, maintains rolling context, and keeps coding/chat agents unblocked. Uses Scout LLM (fast Cerebras) for tool proposals, Bandit layer (learned policy) for ranking, and Rules engine for safety gates. Integrates with CMC (decisions), HHNI (semantic search), VIF (quality gates), SEG (evidence chains), and TCS (timeline). Provides deterministic, inspectable control loop: Observe → Propose → Score → Plan → Execute → Validate → Learn. Enables autonomous operation with confidence ≥0.70.
