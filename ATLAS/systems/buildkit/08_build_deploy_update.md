# Build, deploy, update

**Images** **built** **with** **BuildKit** **are** **deployed** **via** **registry** **push** **then** **kubelet/CRI** **pull** **—** **the** **build** **engine** **is** **not** **the** **cluster** **runtime** (`INFERRED` **pipeline** **sketch**).
