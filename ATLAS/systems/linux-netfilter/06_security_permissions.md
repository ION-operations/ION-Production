# Security and permissions

**Installing** **rules** **requires** **`CAP_NET_ADMIN`** **(and** **related)** **capabilities** **on** **Linux;** **LSM** **policy** **may** **further** **constrain** **who** **can** **change** **firewall** **state** (`DOCUMENTED`/`INFERRED`).
