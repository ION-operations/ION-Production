# JARVIS Tournament Phase 1 - Masterpiece Gate

**Status:** active tournament packet
**Purpose:** constrain the first round to one production-grade shell plus one masterpiece page, so proposals can be reviewed before broader build-out.

---

## 1. Phase 1 Objective

Do not build the whole app.

Build just enough of JARVIS to prove:
- your shell logic is right
- your workspace model is right
- your data-truth signaling is right
- your chosen flagship page is genuinely excellent

This is a proposal-through-code phase, not a full production commitment.

---

## 2. Required Scope

Every competitor must build:

### Shell
- top bar
- workspace switching
- left drawer
- assistant rail
- bottom drawer or strip

### One masterpiece page

Recommended default:
- `Mission Control`

Allowed alternatives:
- `Dispatch`
- `Agent Workforce`
- `Oracle`
- `Infra Console`

If choosing an alternative, the competitor must justify it in the brief.

---

## 3. Deliverables

Each Phase 1 competitor must submit:
- code for the shell and one page
- one design brief
- one page rationale
- one truth map (`LIVE` / `MOCK` / `OFFLINE` / `SPECULATIVE`)
- one screenshot pack at 3 widths
- one next-phase proposal listing:
  - what expands next
  - what remains uncertain
  - what backend assumptions were required

---

## 4. Review Questions

The operator should review each submission by asking:

1. Does this feel like a real command cockpit?
2. Can I tell what is true vs mocked?
3. Does the shell grammar feel scalable?
4. Is the chosen page exceptional enough to justify continuation?
5. Does this design reduce my cognitive burden?

---

## 5. Approval Outcomes

After Phase 1, each proposal gets one of:
- `APPROVE`
- `REVISE`
- `HOLD`
- `CHERRY-PICK ONLY`

Only approved designs should advance into broader workspace expansion.

---

## 6. Why This Gate Exists

Without this gate, the tournament will likely produce:
- six sprawling partial apps
- too much mock scaffolding
- too little real craft
- hard-to-compare outputs

The gate forces each competitor to show:
- shell intelligence
- page intelligence
- operational taste
- respect for the actual AIMOS/JARVIS thesis
