# Agent Onboarding Quality Standards

**Date:** 2025-11-19
**Status:** ✅ Active
**Purpose:** Quality standards for agent onboarding files

---

## 🎯 **QUALITY PRINCIPLES**

### **Core Principles:**
1. **Accuracy** - All information must be accurate
2. **Completeness** - All required sections must be present
3. **Consistency** - Consistent format across all agents
4. **Maintainability** - Easy to update and maintain
5. **Discoverability** - Easy to find and navigate

---

## 📋 **QUALITY CHECKLIST**

### **README.md Quality:**
- [ ] Agent name and role clearly stated
- [ ] Core system correctly identified
- [ ] All quick links work
- [ ] Status information accurate
- [ ] Relationships clearly defined
- [ ] Principles align with system

### **CONTEXT.md Quality:**
- [ ] Timeline includes key events
- [ ] Keywords are system-specific and relevant
- [ ] Important things are actually important
- [ ] Relationships are accurate
- [ ] Evolution section reflects actual evolution

### **NAVIGATION.md Quality:**
- [ ] All links work correctly
- [ ] Situation-based navigation is helpful
- [ ] Links point to correct files
- [ ] Integration patterns are accurate
- [ ] Search terms are relevant

### **MISSIONS.md Quality:**
- [ ] Consolidation work referenced correctly
- [ ] Phase documents linked correctly
- [ ] Agent-specific missions documented
- [ ] Lessons learned are meaningful
- [ ] Deliverables are accurate

---

## 🔍 **AUDIT CRITERIA**

### **Content Quality:**
1. **Accuracy:** All information must be factually correct
2. **Relevance:** All content must be relevant to the agent
3. **Completeness:** All required sections must be present
4. **Clarity:** All content must be clear and understandable

### **Link Quality:**
1. **Working:** All links must work (no 404s)
2. **Correct:** All links must point to correct files
3. **Relevant:** All links must be relevant to the content
4. **Current:** All links must point to current files

### **Format Quality:**
1. **Consistent:** Format must match templates
2. **Structured:** Structure must be logical
3. **Readable:** Content must be easy to read
4. **Maintainable:** Format must be easy to maintain
