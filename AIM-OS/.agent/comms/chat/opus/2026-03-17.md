## 14:40 — Capsule File Naming Redesign

**COMMAND said:** Improve capsule file naming for clarity, retrieval, organization.

### Problem with current format
```
.agent/comms/capsules/opus/2026-03-17.md    ← everything for the day in one file
```
- Can't tell what a capsule was about without opening it
- All PRE and POST capsules mixed together
- No topic context in the filename
- Hard to search/filter by subject
- Gets long and noisy by end of day

### New naming convention
```
.agent/comms/capsules/{callsign}/YYYY-MM-DD_HHMM_{PRE|POST}_{topic-slug}.md
```

**Examples:**
```
2026-03-17_1419_PRE_mcp-tool-limit-fix.md
2026-03-17_1430_POST_mcp-tool-limit-fix.md
2026-03-17_1440_PRE_capsule-naming-redesign.md
2026-03-17_1445_POST_capsule-naming-redesign.md
```

### Why this works
- **Chronological sort** — filenames sort correctly by timestamp
- **PRE/POST visible** — timing is in the filename
- **Topic visible** — you know what the capsule is about without opening it
- **One capsule per file** — clean, atomic, retrievable
- **No collisions** — timestamp ensures uniqueness
- **Easy grep** — `find *mcp*` shows all MCP-related capsules

### Rules
1. **Topic slug**: lowercase, hyphenated, max 5 words (e.g., `mcp-tool-limit-fix`)
2. **PRE and POST share the same slug** for the same work block
3. **Timestamp**: HHMM in 24hr format from the local clock
4. **One capsule per file** — never append to existing capsule files
5. **Content format**: unchanged — still CAPSULE v1 protocol with 7 required fields
