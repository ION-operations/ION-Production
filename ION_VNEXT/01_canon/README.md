# ION_VNEXT Canon

Status: candidate skeleton only
Created: 20260519T195049Z

This directory is the proposed single source of organizational truth for ION vNext.

Files:

- `WORKSPACE_CANON.yaml`: top-level roots and lifecycle contract.
- `FAMILY_REGISTRY.yaml`: family ownership and legacy source-pool mapping.
- `PATH_POLICY.yaml`: read/write/private/path boundary policy.
- `STATE_LIFECYCLE.yaml`: how material becomes state.
- `LEGACY_SOURCE_POOLS.yaml`: how current roots are preserved and audited.
- `MIGRATION_RULES.yaml`: rebuild order and non-actions.
- `QUALITY_STANDARD.yaml`: ION-level quality bar.

No current source is migrated in M25.
