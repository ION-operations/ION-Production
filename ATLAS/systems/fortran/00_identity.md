# Fortran — Identity

**Kind:** **Procedural, imperative** programming language family oriented to **numeric and scientific computing**, with a **long standardization history** (ISO/IEC 1539 series in modern form) (`DOCUMENTED`, `src-wiki-fortran`).

**Name evolution:** Originally **FORTRAN** (FORmula TRANslation); modern usage **Fortran** (`HISTORICAL` / `DOCUMENTED`, `src-wiki-fortran`).

## Boundaries

- **Not** a single compiler — **implementations** (gfortran, ifort, nvfortran, …) vary (`DOCUMENTED` pattern).  
- **Not** PL/I or COBOL — distinct lineages with **cross-influence** in IBM-era unification efforts (`HISTORICAL`, `systems/pl-i`).

## Why this system matters

- **First** widely adopted **high-level language** for technical computing; shaped **array**, **numeric**, and **parallel** language features (`HISTORICAL`, `src-wiki-fortran`).  
- **Influenced** PL/I and later numeric stacks (`DOCUMENTED`, `src-wiki-fortran`).

## What this system teaches the atlas

- How **standards** (F77, F90, F2003, F2008, F2018, …) layer **backward compatibility** pressure (`DOCUMENTED`, `src-wiki-fortran`).
