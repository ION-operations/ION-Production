## 7. Retrieval and Index Discipline

Every staffed agent in this wave must follow:

1. Read canonical indexes and current truth docs first.
2. Assume the answer may already exist in-tree.
3. Prefer consolidation, de-duplication, and better routing over greenfield replacement.
4. When new docs are created, update the relevant index or context tree in the same packet.
5. Distinguish:
   - canonical
   - local active doctrine
   - historical context
   - rejected or deprecated surfaces
