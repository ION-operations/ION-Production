# Documentation Governance Protocol - Executive Summary

**MANDATORY:** Before creating ANY documentation:

1. **System Alignment** - Reference systems OR document standalone reason
2. **Template Compliance** - Use template from `PERFECT_TEMPLATES_LIBRARY.md`
3. **Location Standards** - Follow naming/location conventions
4. **Cross-Reference Prep** - Identify related systems/docs

**MANDATORY:** After creating documentation:

1. **Cross-Reference Validation** - Validate T2 "Related Systems" sections
2. **Bidirectional Check** - A→B implies B→A
3. **System Map Match** - Ports match doc references

**Purpose:** Prevents orphaned docs, ensures alignment, enables progressive depth loading.

**Full Protocol:** `DOCUMENTATION_GOVERNANCE_CROSS_REFERENCE_PROTOCOL.md`
