# ICIP Graph Construction Service – T0 Executive Summary (≈100 words)

ICIP Graph Construction Service builds and maintains the master Code Property Graph (CPG) in Neo4j, transforming language-specific ASTs into unified graph representation combining AST, CFG, and DFG. It performs control flow analysis, data flow analysis, call graph construction, and dependency analysis, enabling incremental updates for real-time processing. The service integrates with CMC for atom storage, HHNI for physics-based retrieval, VIF for provenance tracking, and SEG for knowledge synthesis, serving as foundation for ICIP Platform's advanced codebase intelligence capabilities.
