# Chunks Directory - Systematic Execution Tracking

**Purpose:** Track execution of each chunk with before/during/after documentation  
**Pattern:** Inspired by North Star orchestration process  
**Status:** Active

---

## 📋 **CHUNK STRUCTURE**

Each chunk has 3 files:

### **1. CHUNK_X_Y_PLAN.md** (Before)
- Goal statement
- APOE workflow (which roles, in what order)
- Deliverables (specific files/features)
- Validation criteria (how we know it's done)
- Effort estimate

### **2. CHUNK_X_Y_JOURNAL.md** (During)
- Timestamped entries
- Current role
- Activity/thoughts
- Decisions made
- Issues encountered
- Next steps

### **3. CHUNK_X_Y_COMPLETE.md** (After)
- What was delivered
- Tests written/passing
- Issues and solutions
- Lessons learned
- Next chunk preview

## 🎯 **HOW TO USE THIS**

### **Starting New Chunk:**
1. Read `CHUNK_X_Y_PLAN.md`
2. Create `CHUNK_X_Y_JOURNAL.md`
3. Follow APOE workflow
4. Document as you go

### **During Chunk:**
1. Add journal entries frequently
2. Note decisions and issues
3. Track time spent
4. Stay focused on chunk goal

### **Completing Chunk:**
1. Create `CHUNK_X_Y_COMPLETE.md`
2. Update master tracker
3. Document lessons
4. Preview next chunk
