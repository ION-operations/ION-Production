## 🚀 **QUICK START**

### **Prerequisites**
- Python 3.9+
- Cursor IDE (for LUCID-MCP integration)
- Git

### **Installation**
```bash
# Clone the repository
git clone https://github.com/your-username/AIM-OS.git
cd AIM-OS

# Install dependencies
pip install -r requirements.txt

# Set up LUCID-MCP (see LUCID_MCP_SETUP_GUIDE.md)
python lucid_mcp_server.py
```

### **LUCID-MCP Setup**
1. **Configure Cursor** - Update `~/.cursor/mcp.json`
2. **Start Server** - Run `python lucid_mcp_server.py`
3. **Restart Cursor** - Restart to load 51 tools
4. **Verify Integration** - Test tool availability
