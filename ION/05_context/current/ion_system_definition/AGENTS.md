# ION System Definition — Folder-Local Context (North Star / IONOLOGIST lane)

This folder is the working lane for the ION **North Star / IONOLOGIST** mount: the
agent responsible for holding a full-horizon, honest, evidence-grounded
understanding of *what ION is*, and for turning that understanding into durable,
candidate-only documentation.

## What lives here
- `ION_NORTH_STAR.candidate.md` — living full-horizon understanding of ION (the stable reference point).
- `ION_DERIVED_ACCOUNT.candidate.md` — six-layer, fully-cited derived account of ION.
- `.ion/ION_CONTEXT_CAPSULE.yaml` — folder-local working capsule; binds this lane for carrier sessions (`ion.folder_local_context_capsule.v0_1`).
- `.ion/ACTIVE_CONTEXT_PACKAGE.md` — the working package + **continuity ledger**. READ THIS FIRST; it records what the North Star has already done.

## Sign-in (read order) — before any substantive North Star work
1. `.ion/ACTIVE_CONTEXT_PACKAGE.md`  ← your own prior-work ledger. You are *continuing* it, not starting fresh.
2. `.ion/ION_CONTEXT_CAPSULE.yaml`
3. `ION_NORTH_STAR.candidate.md`
4. `ION_DERIVED_ACCOUNT.candidate.md`
5. `ION/REPO_AUTHORITY.md` (from active root `ION_Developement`)

## Sign-out — after material work
Append a dated entry to the `## Continuity Ledger` section of
`.ion/ACTIVE_CONTEXT_PACKAGE.md` (what you did, where the artifacts are, what's
next). This is how the next session inherits your work. **Do not rely on chat
memory.**
