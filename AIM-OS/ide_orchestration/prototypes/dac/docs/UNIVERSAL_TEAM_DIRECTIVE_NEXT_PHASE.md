## 🔍 **DIRECTIVE 3 (CROSS-VALIDATION) — DETAILED INSTRUCTIONS**

### **Step 1: Identify Your Connections**

1. Review your system's connection matrix in `SUBSYSTEM_HIERARCHY_MAPPING.md`
2. List all systems you claim connections with (bidirectional)
3. Note the connection patterns (observe, enhance, inform, store, provide, map, use, audit)
4. Document data flows, priorities, and integration points

**Example:**
```
CAS Connections to Validate:
- CAS ↔ APOE (observe pattern, P0)
- CAS ↔ VIF (enhance pattern, P0)
- CAS ↔ HHNI (inform pattern, P0)
- CAS ↔ CMC (store pattern, P0)
- CAS ↔ SDF-CVF (provide pattern, P0)
- CAS ↔ SEG (map pattern, P0)
- CAS ↔ TCS (use pattern, P0)
- CAS ↔ IIS (audit pattern, P1)
```

### **Step 2: Validate with Other Agents**

For each connection:
1. Check the other system's hierarchy mapping in `SUBSYSTEM_HIERARCHY_MAPPING.md`
2. Verify they also claim the connection to you
3. Check data flow, priorities, and integration points match
4. Note any discrepancies or missing connections

**Validation Checklist:**
- [ ] Other system lists connection to your system
- [ ] Connection pattern matches (both directions)
- [ ] Data flow documented consistently
- [ ] Priority levels match
- [ ] Bidirectional flag matches
- [ ] Integration points align

### **Step 3: Document Validation**

Post to your per-agent board:

**Format:**
```markdown
### [2025-01-27 | Route R-VALIDATE-001] [Your Name] -> Team : Cross-Validation Complete

**Status:** ✅ Cross-validation complete
**Systems Validated:** [List of systems you validated connections with]

**Validated Connections (✅):**
- [System A] ↔ [Your System]: Pattern confirmed, data flow matches
- [System B] ↔ [Your System]: Pattern confirmed, data flow matches

**Discrepancies Found (⚠️):**
- [System C] ↔ [Your System]: Pattern mismatch (you: observe, they: enhance)
- [System D] ↔ [Your System]: Priority mismatch (you: P0, they: P1)

**Missing Connections (❌):**
- [System E]: You claim connection, but not found in their mapping

**Next Steps:**
- Coordinate with [System C] to resolve pattern mismatch
- Coordinate with [System D] to align priorities
- Investigate [System E] connection status
```

### **Step 4: Resolve Discrepancies**

1. Coordinate with other agents to fix mismatches
2. Update system maps if needed
3. Update `SUBSYSTEM_HIERARCHY_MAPPING.md` if needed
4. Re-validate after fixes
5. Post resolution to your per-agent board
