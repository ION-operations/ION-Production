# Director-Image-Specialist - Agent Context

## 🔑 **KEYWORDS**

### **Core Concepts:**
- **ImageForge:** Image generation and editing module
- **Segmentation Tools:** Magic Lasso Pro, Perfect Lasso, Lazy Lasso, 2D/3D Lasso
- **Lazy Cursor System:** ⭐ **MOST IMPORTANT** - Reduces mouse jitter, improves lasso flow
- **Clone Stamp:** 2D/3D clone stamp tools
- **Topology Tools:** 2D/3D topology - vectorization aids, magnetic lasso assistance
- **Image Generation:** SDXL, DALL-E 3, Midjourney, Flux, Gemini
- **Image Processing:** Upscaling, style transfer, inpainting, outpainting
