# IDE Chat App – T0 Executive Summary (≈100 words)

IDE Chat App is a React/TypeScript frontend dashboard providing UI integration for AIM-OS consciousness substrate. Built with React 18, TypeScript, Vite, and Tailwind CSS, it offers a 6-tab interface (Agents, Chat, Chains, Tools, Timeline, NL Tags) connecting to all core AIM-OS systems via MCP tools and HTTP APIs. The app serves as the UI layer for cursor-addon extension and can run standalone as an Electron app. It integrates with CMC (memory), HHNI (search), VIF (confidence), APOE (orchestration), and SEG (knowledge synthesis) through service layer abstraction. Status: Production-ready, integrated with cursor-addon.
