# Dynamic Cursor Rules System – T0 Executive Summary (≈100 words)

Dynamic Cursor Rules System provides context-aware rule selection for Cursor IDE, dynamically loading relevant rule partitions based on current task context. Enables intelligent rule management through context analysis, partition selection, and rule integration. Key features include context-aware rule loading, dynamic partition management, rule prioritization, and seamless IDE integration. Integrates with AIM-OS systems for enhanced rule intelligence and context understanding. Agent Identity Protocol ensures proper context attribution and continuity across rule operations.
