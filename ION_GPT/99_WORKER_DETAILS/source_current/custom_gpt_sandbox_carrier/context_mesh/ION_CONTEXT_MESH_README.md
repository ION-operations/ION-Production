# ION Context Mesh — v4.7 Dogfood

This folder contains the carrier-local context mesh manifest generated from
`ION_CONTEXT_CAPSULE.yaml` files. It proves the folder-capsule idea is not only
a design: the package now discovers capsules, computes hashes, records
inheritance edges, and exports relevant capsules into transfer packages.

The manifest is candidate context and must not be treated as accepted state
without receipt/settlement.
