## What Is Code Property Graph?

The Code Property Graph (CPG) is the cornerstone of ICIP's architecture and the **primary data source** for AIM-OS's consciousness systems. It serves as the unified data model that creates a single, holistic, and queryable source of truth for all codebase intelligence, enabling AIM-OS to understand and interact with codebases at a deep semantic level.

## Core Innovation

The CPG unifies three critical code representations:
- **Abstract Syntax Tree (AST)**: Code's grammatical structure
- **Control Flow Graph (CFG)**: Execution order mapping
- **Data Flow Graph (DFG)**: Data movement tracking

## Technical Foundation

### Graph Database
- **Neo4j**: Native graph traversal and querying
- **Cypher**: Powerful graph query language
- **Performance**: Optimized for large-scale codebases
- **Scalability**: Horizontal scaling with clustering

### Data Model
- **Nodes**: Functions, classes, variables, statements
- **Edges**: Calls, inheritance, data flow, control flow
- **Properties**: Types, names, locations, metadata
- **Relationships**: Semantic connections between code elements
