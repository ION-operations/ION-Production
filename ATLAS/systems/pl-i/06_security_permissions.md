# Security and permissions

## Language-level safety

**Strong typing** and **exception handling** are design themes; they reduce but do not eliminate **memory safety** issues in systems programming styles (`DOCUMENTED`, `src-wiki-pl-i-goals`).

## Platform security

Access control, sandboxing, and **capability** systems are **host OS** responsibilities — PL/I programs inherit whatever the runtime/OS provides (`INFERRED`).

## Historical note

Relational extensions and **Codd**-related work are noted in encyclopedic histories (`HISTORICAL`, `src-wiki-pl-i-date-codd`).
