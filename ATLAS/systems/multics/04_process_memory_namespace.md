# Process, memory, and namespace model

- **Processes** as multiprogrammed units subject to supervisor policy (`HISTORICAL`).  
- **Segments** as addressable, protected units; foundation of access control discussion in Saltzer et al. (`HISTORICAL`, `paper-saltzer-1974-protection`).  
- **Naming** integrated with information system design (contrast with later pure path-only namespaces — `HISTORICAL`).

**INFERRED (weak):** Modern “namespace” vocabulary maps only partially; prefer period terminology in curated text.
