# Process, memory, namespace

**QEMU** **runs** **as** **host** **userspace** **processes** **with** **guest** **RAM** **mapped** **and** **managed** **by** **the** **VMM;** **namespaces** **and** **cgroups** **apply** **to** **the** **QEMU** **process** **like** **other** **host** **workloads** (`INFERRED`).
