# ION GPT

This folder is the non-coder setup area for the ION Custom GPT.

Use these folders in order:

```text
01_GPT_BUILDER_INPUTS/      paste this into GPT Builder Instructions
02_PACKAGES_TO_UPLOAD/      upload these zips as GPT Knowledge
03_ACTIONS/                 paste these two Action schemas
04_CURRENT_SANDBOX_CARRIER/ current behavior contract summary
05_CONTINUITY_TRANSFER/     next-chat continuity packages and prompts
90_HISTORICAL_ZIPS/         old evidence only
99_WORKER_DETAILS/          AI/Codex worker details only
```

## Start here

Open:

```text
01_GPT_BUILDER_INPUTS/README.md
```

Then use:

```text
01_GPT_BUILDER_INPUTS/CURRENT_INSTRUCTIONS_TO_PASTE.md
02_PACKAGES_TO_UPLOAD/UPLOAD_THESE_ZIPS/
03_ACTIONS/
05_CONTINUITY_TRANSFER/
```

## Do not use by default

- `90_HISTORICAL_ZIPS/` is old package evidence.
- `99_WORKER_DETAILS/` is for AI/Codex workers and audits.
- Do not install schemas or zips from historical folders unless a current release sheet explicitly says so.
