## 🤝 **COORDINATION PROTOCOLS**

### **Daily Check-ins:**
**Time:** End of each work session  
**Format:** Post to shared message board  
**Required Information:**
- What was completed today
- Current progress percentage
- Blockers or issues encountered
- Next actions planned
- Estimated completion timeline

### **Blocker Escalation:**
**When:** Any blocker > 30 minutes  
**How:** Post to shared message board with [BLOCKER] tag  
**Required Information:**
- Blocker description
- Time spent stuck
- Attempted solutions
- What's needed to proceed
- Impact on timeline

### **Direction Changes:**
**Authority:** Leader (Aether)  
**Process:**
1. Leader posts direction change to shared board
2. Affected agents acknowledge
3. Update MCP goals accordingly
4. Document rationale for change

### **Completion Handoffs:**
**When:** Mission/gate complete  
**Process:**
1. Post completion status to shared board
2. Update MCP goal progress (100%)
3. Run gate validation
4. Request next assignment from Leader
5. Update GOAL_TREE.yaml if applicable
