# ALGOL — Identity

**Kind:** **Family** of **algorithmic** programming languages — **ALGOL 58**, **ALGOL 60**, **ALGOL 68** are distinct designs with different syntax and goals (`DOCUMENTED`, `src-wiki-algol`).

**Standards / reports:** **ALGOL 60** circulated as **international** **report** (not one modern ISO package like C); **ALGOL 68** had **revised report** editions (`HISTORICAL`, `src-wiki-algol`).

## Boundaries

- **Not** one **runtime** — **implementations** and **dialects** differ (`HISTORICAL`).  
- **Not** **Fortran** — different committee lineage and syntax culture (`DOCUMENTED` comparative).

## Why this system matters

- **Block structure**, **lexical** **nesting**, **BNF**-driven **syntax** description — shaped **PL/I**, **Pascal**, **C** lineage indirectly (`DOCUMENTED` / `HISTORICAL` per claim).  
- **Portable** **algorithm** **expression** ideal vs **vendor** **lock-in** (`HISTORICAL` narrative).

## What this system teaches the atlas

- How **language families** split (60 vs 68) and how **standardization** **before** **ISO** **era** worked.
