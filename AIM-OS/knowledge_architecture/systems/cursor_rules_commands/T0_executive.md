# Cursor Rules & Commands - Executive Summary

**Cursor 2.0** introduces sophisticated Rules (persistent AI context) and Commands (reusable workflows triggered with `/`). AIM-OS leverages **4 rule types** (Always/Auto-Attached/Agent Requested/Manual) for context-aware AI guidance and **custom commands** in `.cursor/commands/` for workflow automation. Rules provide operational standards (`base-rules.mdc` always applied, `dynamic-rules.mdc` context-aware), while commands enable one-touch execution of complex tasks like `/create-t0-t4-docs` or `/run-tests`. System enables autonomous operation with quality enforcement, reducing repetitive workflows to simple slash commands. **Status:** Production-ready with 8 core commands deployed.
