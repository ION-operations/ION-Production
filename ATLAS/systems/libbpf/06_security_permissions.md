# Security and permissions

**Capabilities** **and** **privilege** **to** **load** **BPF** **depend** **on** **kernel** **policy** **and** **deployment** **context** **—** **libbpf** **is** **the** **API** **surface,** **not** **the** **security** **model** (`DOCUMENTED` / `INFERRED`).
