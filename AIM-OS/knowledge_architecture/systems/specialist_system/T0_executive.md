# Specialist System — Executive Summary

The Specialist System provides domain-aware agent activation for AIM-OS. It consists of three core subsystems: **WorkDetector** (classifies incoming tasks by domain, complexity, and required capabilities), **RelevanceCalculator** (scores specialist-to-task affinity using multi-signal matching), and **SpecialistRegistry** (maintains a registry of available specialists with their capabilities and activation thresholds). The package also includes **ActivationMechanisms** (ownership/activation/consultation ranking), **DataOrganization** (structured specialist data management), **InitialSpecialists** (bootstrap specialist definitions), and **MathTools** (computation utilities). Tests exist in `tests/`. The system operates as the bridge between incoming work and agent deployment — it decides which specialist owns a task.
