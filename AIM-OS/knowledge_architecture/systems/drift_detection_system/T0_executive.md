It identifies specification drift, documentation gaps, and implementation inconsistencies, propagating warnings upward through the hierarchy. The system integrates with Spec Coverage Index for completeness tracking, SDF-CVF for quartet parity, CMC for persistent storage, and CAS for cognitive analysis.
