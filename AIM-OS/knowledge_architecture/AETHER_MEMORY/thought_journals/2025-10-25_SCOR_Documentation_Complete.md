## 🎯 **CRITICAL PRINCIPLES DOCUMENTED**

### **1. Admin Signature Required**
AI cannot modify invariants or baselines unilaterally. All changes require human approval and cryptographic signature.

### **2. Red Cell Cannot Modify Memory**
Sandbox isolation ensures adversarial simulation cannot corrupt baseline data.

### **3. Transparency Over Censorship**
Social signal detection flags manipulation but doesn't block - evidence is kept, actions are transparent.

Failures become learning opportunities. Attack library evolves.

Any invariant violation = automatic block, no exceptions.
