## 🎯 **HOW TO USE THIS SYSTEM**

### **For Finding Agents:**
1. Check [Agent Profile Registry](./AGENT_PROFILE_REGISTRY.md) for complete profiles
2. Filter by rating, specialty, or status
3. Review integration partners for collaboration
4. Check onboarding files for detailed context

### **For Creating New Agents:**
1. Use [Agent Profile Template](./AGENT_PROFILE_TEMPLATE.md)
2. Follow onboarding protocol structure
3. Add to [Agent Profile Registry](./AGENT_PROFILE_REGISTRY.md)
4. Create 4 onboarding files
5. Update this index

### **For Agent Selection:**
1. Review agent profiles for required capabilities
2. Check ratings (must be ≥0.70 for task)
3. Review integration partners
4. Check status (ready/need build/enhance/future)
