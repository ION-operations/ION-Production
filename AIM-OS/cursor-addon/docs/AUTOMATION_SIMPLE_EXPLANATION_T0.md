# Automation Systems – Simple Explanation (≈100 words)

**What it does:** Lets Cursor AI agents work by themselves for hours or days, doing tasks like fixing code, writing tests, or refactoring. You start them, they work autonomously, and you can watch their progress in a dashboard.

**How it works:** You type a command (like `/agent-start`), it starts a Cursor agent in the background, the agent does work autonomously, and you see updates in real-time through a dashboard. Messages between components are guaranteed to arrive (bulletproof messaging).

**Capabilities:** Run agents for hours/days, monitor progress, auto-recover from failures, checkpoint progress, control via commands or dashboard.

**Status:** Infrastructure ready, agent control implemented, pending API research.
