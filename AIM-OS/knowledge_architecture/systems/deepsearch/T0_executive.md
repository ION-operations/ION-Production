# DeepSearch - T0 Executive Summary (≈100 words)

**DeepSearch** is a sovereign local intelligence engine providing web and filesystem search capabilities for AIM-OS IDE systems. It operates independently from HHNI, using its own SQLite-based index, trust scoring algorithm, and entropy calculation. Key features include async web crawling, polite rate limiting, and persistent master index. DeepSearch integrates with IDE systems (lucid-chat, lucid-ide) but does not enhance HHNI—it's a separate integration system for external search needs. Classification: **Integration System** (not an enhancement to HHNI).
