# Security and permissions

**vhost-user** **sockets** **and** **shared** **memory** **regions** **must** **be** **protected** **by** **host** **permissions;** **misconfiguration** **can** **bridge** **guest** **I/O** **into** **the** **wrong** **host** **context** (`INFERRED`).
