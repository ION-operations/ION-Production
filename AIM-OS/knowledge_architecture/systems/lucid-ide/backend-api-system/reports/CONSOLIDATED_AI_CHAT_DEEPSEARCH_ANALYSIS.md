**System 1 (Fast Thinking):**

- Pattern recognition, perception, heuristic judgments
- LLMs excel here

**System 2 (Slow Thinking):**
- Slow, deliberative, step-by-step, explicit
- Planning, formal deduction, complex reasoning
- Symbolic AI provides this

**Neuro-Symbolic AI Integration:**
Goal: Create "best-of-both-worlds" system
- Neural side: Learning from data, robustness, pattern recognition
- Symbolic side: Explainability, provable correctness, structured reasoning

**Kautz's Taxonomy (6 Patterns):**
1. Symbolic → Neural → Symbolic
2. Symbolic[Neural]
3. Neural | Symbolic
4. Neural: Symbolic → Neural
5. NeuralSymbolic
6. Neural: Symbolic

- Pattern #6: Neural: Symbolic

- Enables hybrid cognitive architecture
